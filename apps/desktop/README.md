# LxMine 桌面端

以 MineRadio 原作者 2.2.0 为视觉与桌面基座，融合 LX Music 音源和音乐管理。当前正在重建与接入，完整进度见 ../../docs/PLAN.md。

使用 PowerShell 7，在本目录执行 npm ci，然后 npm start；npm run build:win:dir 构建免安装目录，npm run build:win 构建 LxMine 安装包。

原作者来源、版本与修改边界见 ../../docs/UPSTREAM.md。原 MineRadio 的许可证、作者和第三方声明保留在 LICENSE、NOTICE.md 和 docs/THIRD_PARTY_PORTS.md。本版本已关闭原上游更新源。
