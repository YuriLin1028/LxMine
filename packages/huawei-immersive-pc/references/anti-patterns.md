# 反模式：症状、原因、修复

这些不是理论上的“坏味道”，而是 LxMine 实际出现过的缺陷。每条给出可观察的
症状，方便你在自己的项目里快速定位。

---

## A. 材质与层级

### A1. 文字跟着玻璃一起糊/扭

**症状**：按压或拖动时标题、图标、数字轻微移动或发虚；截图对比文字像素差
明显大于 0。

**原因**：`filter` 或 `backdrop-filter` 加在了宿主/父容器上，内容与材质在
同一滤镜树里；或者对宿主做了 transform。

**修复**：

- 宿主只做布局/命中；
- 插入独立 `.hx-glass__skin`，所有光学效果只在皮肤上；
- 形变只改皮肤 transform；
- 确保宿主的 `background` 透明。

### A2. 越叠越白，像磨砂塑料

**症状**：控件内部发灰、发白，背景颜色被“洗掉”。

**原因**：父级 blur + 子级 backdrop-filter + 伪元素高光多层叠加；或每个
嵌套的 `.hx-glass` 都在采样一次背景。

**修复**：

- 一个宿主一张皮肤；
- 不在玻璃内部再放玻璃；
- 去掉父级 `filter`；
- 需要嵌套时，内层用实色/半透明，不重复采样。

### A3. 折射固定不动，像贴图

**症状**：背景滚动/视频播放时，控件内部图案不变。

**原因**：使用截图/预渲染纹理作为材质；或 `background-image` 模拟折射。

**修复**：

- 使用实时 `backdrop-filter: url(#filter)`；
- 用网格/视频背景测试；
- 确认 filter 的 `SourceGraphic` 是实时 backdrop，而不是静态图。

### A4. 边缘有一圈脏白/乳白

**症状**：外缘比中心亮很多，或出现不自然的白圈。

**原因**：中心和边缘共用一张模糊图；边缘 mask 没有独立；高光叠加过多。

**修复**：

- 边缘用独立 `edgeSigma` 和独立位移；
- 用 B 通道 rim mask 只在窄带混合；
- 降低 `envLift` / 去掉额外白色描边；
- 检查 `envStart/envWidth`。

### A5. 胶囊上下沿是尺子直线

**症状**：圆角正确，但上下边完全水平，缺少真机的轻微外凸。

**原因**：只有 SDF 法线，没有切向肩部位移。

**修复**：

- 加入 `tangentGain/tangentCap/tangentDecay`；
- 用水平网格背景验证；
- 相位误差目标 ≤ 0.75 CSS px。

### A6. 球面有等高线/层纹

**症状**：圆形控件内部出现一圈圈细线，像地形图。

**原因**：8 位位移场量化；提高分辨率无效。

**修复**：

- 对**位移结果**加小半径 `resultSigma`（0.5–1.0）；
- 不要降低 `amplitude` 来掩盖；
- 边缘高光保持独立，不要一起模糊。

### A7. 大面板中间也在扭曲

**症状**：文字区域被拉扯，阅读困难。

**原因**：`decay` 太大，法线衰减太慢；或 `resultSigma` 太大。

**修复**：

- 降低 `decay`（如 2.0–2.5）；
- 确认文字区域不在滤镜层；
- 面板越大，位移越应集中在边缘。

### A8. 圆角边缘出现矩形硬边

**症状**：玻璃外有一圈方形裁切，或阴影被切平。

**原因**：filter 区域小于皮肤；皮肤没有覆盖边框盒；`overflow:hidden` 裁切。

**修复**：

- filter `x=0 y=0 width=100% height=100%`；
- 皮肤 inset 为负边框宽度；
- 宿主不要裁切皮肤；
- 检查 `feImage` 宽高与量化尺寸。

### A9. 高 DPI 下边框消失/变粗

**症状**：125%/150% 下 0.5px 边框不可见或变成 1px 实线。

**原因**：固定 0.5px 被物理像素舍入。

**修复**：

- 发丝线使用 `1 / devicePixelRatio`；
- 分别测试 100/125/150/200%；
- 不要用 `transform: scaleY(.5)` 伪造。

## B. 性能

### B1. 窗口缩放时 50–150ms 尖峰

**症状**：拖动窗口边缘，画面卡顿；trace 显示 Layout/UpdateLayerTree 峰值。

**原因**：ResizeObserver 回调里对每个控件交替 `measure → write`，每次写都
强制下一轮布局。

**修复**：

- 先快照所有几何（纯读）；
- 再按 4ms 预算写皮肤；
- 未完成的留到下一帧；
- 跳过签名未变的宿主。

### B2. 弹窗打开掉帧

**症状**：菜单展开动画前几帧卡顿。

**原因**：每帧重建 filter；打开时反复测宽高；材质在动画开始后才准备。

**修复**：

- 插入后测一次尺寸；
- `HxMaterial.prepare` 后再播放；
- filter 按尺寸/圆角缓存；
- 动画期间不读布局。

### B3. GPU 内存持续增长

**症状**：反复缩放/开关弹窗后显存上涨。

**原因**：每个中间尺寸都保留 filter；关闭的菜单没有移除。

**修复**：

- 尺寸量化到 2px；
- 缓存上限 + 未使用淘汰；
- 关闭后移除菜单节点；
- 不在隐藏页面保留大量皮肤。

### B4. 长时间 100% GPU

**症状**：空闲时风扇转、功耗高。

**原因**：动画结束后 rAF 未停；Canvas/视频一直跑；弹簧常驻。

**修复**：

- 弹簧无活动时停止 rAF；
- 隐藏页面暂停 Canvas；
- 菜单关闭后取消 WAAPI fill；
- 限制同时可见的玻璃控件数量。

### B5. 用隐藏窗口测帧率

**症状**：报告很漂亮，实际使用卡顿。

**原因**：窗口不可见/最小化时 Chromium 降频或暂停合成。

**修复**：

- 真实可见窗口；
- 关闭后台节流；
- DPR 固定；
- 预热后采样；
- 场景间冷却。

### B6. 通过降低测试分辨率“通过”

**症状**：门禁过了，但实际 4K 屏上模糊/卡顿。

**原因**：测试用低 DPR/小窗口，或隐藏窗口。

**修复**：

- 按目标 DPR 测试；
- 打包后实际 exe 复测；
- 不修改测试分辨率来规避预算。

## C. 弹窗

### C1. 从左上角展开

**症状**：菜单像从自己的角上缩放，而不是从按钮中心长出。

**原因**：`transform-origin` 默认 `50% 50%` 或 `0 0`；没有按锚点计算。

**修复**：

- 用触发器中点减菜单位置计算 origin；
- 写入 `transform-origin`；
- 记录 `originX / width` 决定横向方向。

### C2. 底部菜单被截断

**症状**：靠近窗口底部的菜单超出视口。

**原因**：只向下展开，没有翻转；或没有 max-height。

**修复**：

- 下方放不下时翻到上方；
- 上方也放不下时选择空间更大的一侧；
- `max-height` + 内部滚动；
- 底部安全区 12px。

### C3. 菜单自己的左上角在屏幕外

**症状**：靠近右边缘时菜单被裁切或水平滚动。

**原因**：只 clamp 了 left，没有考虑 max-width。

**修复**：

- `max-width: min(340px, 100vw - 24px)`；
- `left = clamp(left, 16, vw - 16 - width)`；
- 长文本省略，不换行撑宽。

### C4. 选中行画了勾

**症状**：菜单右侧出现 ✓，与手机不一致。

**原因**：沿用桌面菜单习惯。

**修复**：

- 删除勾选图标；
- 用系统蓝文字 + 蓝底表达选中；
- `aria-checked` 保留给屏幕阅读器。

### C5. 菜单有标题/分组

**症状**：顶部多一行“选择音质”，高度多 40px。

**原因**：把桌面下拉菜单的标题带进来。

**修复**：

- 删除标题；
- 触发器本身已经表达语义；
- 如需分组，用分隔线，不加标题。

### C6. 关闭后才执行 action 反了

**症状**：点击菜单项后新页面被菜单盖住，或菜单残留在新路由上。

**原因**：先执行 action，再关闭；或 close 是异步但 action 立即切换路由。

**修复**：

- 先 `close()`（150ms 动画）；
- 再执行 action；
- 或在 action 前移除菜单节点；
- 保证同时只有一个 popup。

### C7. 滚动时菜单跟着漂

**症状**：页面滚动，菜单停在原地或抖动。

**原因**：`position:absolute` 相对滚动容器；或实时 reposition。

**修复**：

- `position:fixed`；
- 打开时计算一次；
- 滚动时关闭（原生行为）。

### C8. Escape 穿透

**症状**：按 Esc 关闭菜单的同时，后面的详情页也关了。

**原因**：多个 keydown 监听都处理 Escape，没有 stopPropagation/捕获层级。

**修复**：

- 菜单/模态在捕获阶段处理并 stopPropagation；
- 全局只处理最上层；
- 关闭后移除监听。

### C9. 菜单高度不是 152

**症状**：三行 48px，但总高 153/154px。

**原因**：0.5px 边框 + 4px padding 的物理像素舍入。

**修复**：

- `paddingBlock: calc(4px - borderWidth)`；
- 用实际 DOM 高度断言；
- 高 DPI 下复测。

## D. 动效与编排

### D1. 详情页背景和 dock 同时动

**症状**：进入详情时“刷”一下全部出现，没有层次。

**原因**：0ms 同时做 dock 位移和背景去模糊。

**修复**：

- 播控先到位；
- 620ms 后再移除进入态，让背景显影；
- 退出先保持 140ms，再淡出。

### D2. 详情退出跳变

**症状**：点返回，背景突然消失，dock 瞬移。

**原因**：计时器未清理；或先移除 DOM 再动画。

**修复**：

- 清理所有 timer；
- 先加 leaving，等淡出；
- 620ms 后移除；
- 快速开关用 token 防旧回调。

### D3. 搜索双节点交叉淡入

**症状**：搜索球和搜索框交界处出现两个材质/文字重影。

**原因**：一个球节点 + 一个框节点，透明度交叉。

**修复**：

- 只用一个节点；
- 移动 DOM 后测目标矩形；
- FLIP 连续形变；
- 关闭反向。

### D4. 搜索原点是 0×0

**症状**：打开搜索时从左上角/屏幕外飞入。

**原因**：先加打开态/隐藏球，再测起始矩形。

**修复**：

- 在布局变化前测起始 rect；
- 确认宽高 > 0；
- 目标 rect 在布局稳定后测；
- `transform-origin: top left`。

### D5. 弹窗用 CSS transition 无法中途关闭

**症状**：展开到一半点击外部，菜单先弹回全尺寸再消失。

**原因**：CSS animation 不暴露当前相位；关闭重新从 scale(0) 开始。

**修复**：

- 用 WAAPI；
- 关闭时读当前矩阵/opacity；
- 取消旧动画；
- 从当前值收起。

### D6. 动画结束后元素不可点

**症状**：菜单视觉上已消失，但仍挡住点击；或反之。

**原因**：`fill: forwards` 保留了 transform/opacity，节点未移除。

**修复**：

- 完成后 cancel；
- 移除节点和遮罩；
- 关闭期间 pointer-events 正确。

### D7. 用 `transition: all`

**症状**：改变一个属性导致意外动画/布局抖动。

**原因**：`all` 包含 width/height/padding 等布局属性。

**修复**：

- 明确列出属性；
- 布局属性与 transform/opacity 分开；
- 高频动画只用 transform/opacity。

### D8. 详情页窄窗口播控缩水

**症状**：窄窗口详情只剩 5 个按钮，封面变小。

**原因**：复用了紧凑主页的 `.is-compact` 样式。

**修复**：

- 详情强制 56px、44/38、38/40、7 键；
- 容器查询只把部分控制收进“更多”；
- 不要用手机两栏的 44px dock 套详情。

## E. 窗口

### E1. 最大化盖住任务栏

**症状**：点最大化，任务栏被窗口覆盖。

**原因**：用 `display.bounds` 或 `setFullScreen(true)` 实现最大化。

**修复**：

- `win.maximize()`；
- 或 `setBounds(display.workArea)`；
- 全屏是独立按钮。

### E2. 最大化/全屏还有圆角

**症状**：屏幕角上出现 20px 黑/透明缺口。

**原因**：页面圆角状态没有跟随窗口状态。

**修复**：

- 监听 maximize/unmaximize/fullscreen；
- 给 body 加 class；
- 窗口 surface/caption/splash 圆角置 0。

### E3. 启动时白闪

**症状**：打开应用先白屏再出现界面。

**原因**：`show:true` 早于页面就绪。

**修复**：

- `show:false`；
- `ready-to-show` 后再 show；
- 启动画面同色背景；
- 避免透明窗口先显示空白。

### E4. 拖动区挡住按钮

**症状**：标题栏附近的按钮点不动。

**原因**：拖动区 `-webkit-app-region: drag` 覆盖了按钮；或按钮没有 `no-drag`。

**修复**：

- 拖动区限制高度；
- 按钮显式 `no-drag`；
- z-index 正确。

### E5. 透明窗口边缘黑边

**症状**：圆角外有一圈黑/灰。

**原因**：`backgroundColor` 不是全透明；或页面 body 有不透明背景。

**修复**：

- `#00000000`；
- body 透明；
- 窗口 surface 负责背景；
- 检查 DWM 阴影。

### E6. 跨屏错位

**症状**：拖到副屏后最大化/还原位置错误。

**原因**：使用主屏尺寸/工作区。

**修复**：

- `screen.getDisplayMatching(win.getBounds())`；
- 保存/恢复时 clamp；
- 处理不同 DPI。

## F. 验收

### F1. 改源码后继续用旧批准

**症状**：门禁显示 PASS，但实际包是旧材质/新代码。

**原因**：批准报告没有绑定源文件哈希。

**修复**：

- 报告记录源码/基准/验证器 SHA-256；
- 打包前逐项校验；
- 测试开始即撤销旧批准。

### F2. 负对照也能通过

**症状**：关闭折射的实现仍被评为 PASS。

**原因**：阈值太松，或分析区域避开了边缘。

**修复**：

- 加入负对照；
- 检查折射带/轮廓区域；
- 负对照必须失败，否则门禁无效。

### F3. 只报告 SSIM

**症状**：SSIM 很高，但边缘明显错误/层纹。

**原因**：全局指标掩盖局部问题。

**修复**：

- 同时报告 MAE/rim/centre/outside/outline；
- 球面 Laplacian；
- 胶囊肩部相位；
- 视觉三联图。

### F4. 删除失败样本

**症状**：报告很漂亮，但某些背景/尺寸缺失。

**原因**：只保留通过样本。

**修复**：

- 样本矩阵固定；
- 缺一失败；
- 失败原图保留；
- 替换基准需记录原因。

### F5. 用截图纹理提分

**症状**：静态对比很好，动态背景穿帮。

**原因**：把真机截图作为材质贴图。

**修复**：

- 实时 backdrop；
- 动态网格/视频测试；
- 负对照检查。

## G. 可访问性

### G1. 菜单只能用鼠标

**症状**：键盘用户无法选择。

**原因**：没有 role/tabindex/方向键。

**修复**：

- `role=menu/menuitemradio`；
- roving tabindex；
- 方向键/Home/End/Enter/Esc；
- 焦点归还。

### G2. 焦点不可见

**症状**：Tab 到按钮没有视觉反馈。

**原因**：全局 `outline:none`。

**修复**：

- `:focus-visible` 2px 白色 outline；
- offset 4px；
- 不要移除键盘焦点指示。

### G3. 忽略 reduced motion

**症状**：晕动症用户仍看到长动画/弹跳。

**原因**：只做 CSS media query，JS 动画照旧。

**修复**：

- JS 检查 `prefers-reduced-motion`；
- 弹窗/搜索/弹簧直接落位；
- 保留状态变化，不保留运动。

### G4. 只用颜色表达选中

**症状**：色觉障碍用户无法分辨。

**原因**：只有蓝色文字/背景。

**修复**：

- `aria-checked`；
- 可选的非颜色提示（但不要加勾选图标破坏视觉）；
- 焦点态与选中态区分。

## H. 实现/API

### H1. 在 `pointermove` 里读布局

**症状**：拖动时 CPU 高、掉帧。

**原因**：每次 move 调 `getBoundingClientRect`。

**修复**：

- 按下时缓存 rect；
- move 只用 clientX/Y 做差；
- 需要时在 rAF 中统一读。

### H2. 用 `setInterval` 驱动弹簧

**症状**：不同刷新率下速度不一致，后台仍耗电。

**修复**：

- 用 rAF + dt；
- 无活动停止；
- dt clamp。

### H3. 动态节点没有 prepare

**症状**：菜单第一帧透明/无材质，第二帧才出现。

**原因**：插入后没有立即测量/生成皮肤。

**修复**：

- append 后 `HxMaterial.prepare(node)`；
- 再设置可见/播放动画；
- 避免先显示后补材质。

### H4. 同时打开多个 popup

**症状**：两个菜单重叠，Escape 只关一个。

**修复**：

- 全局单例；
- 打开新菜单前关闭旧菜单；
- 遮罩也只保留一个。

### H5. 关闭时移除节点但没有清理监听

**症状**：内存增长、Escape 触发已销毁的回调。

**修复**：

- close 中移除 keydown/resize/scroll/blur；
- 取消动画；
- 移除 DOM；
- 幂等。

### H6. 用 `innerHTML` 插入不可信内容

**症状**：XSS/布局注入。

**修复**：

- 只传可信模板；
- 用户内容用 textContent/DOM；
- 外部 HTML 先净化；
- CSP 限制。
