# 移植清单：把标准接入一个现有 Windows 应用

这份清单按“先能跑，再像，再稳，再可验收”的顺序排列。每一步都有可观察的
验收条件；不要跳到材质参数微调而忽略窗口或层级问题。

---

## 阶段 0：审计目标应用

- [ ] 技术栈：Electron / WebView2 / Tauri / 其他 Chromium 壳；
- [ ] Chromium 版本 ≥ 120；
- [ ] 是否无边框、透明、可缩放；
- [ ] 是否已有自定义标题栏/拖动区；
- [ ] 是否有全局 `filter` / `backdrop-filter` / 多层模糊；
- [ ] 是否有原生 `<select>` / 系统菜单需要替换；
- [ ] 是否有移动端/窄窗口布局；
- [ ] 现有性能基线（空闲/滚动/弹窗 P95）；
- [ ] 是否支持 `prefers-reduced-motion`；
- [ ] 打包/签名/自动更新流程。

**产出**：一页现状表，标出必须改的层级和窗口配置。

---

## 阶段 1：接入运行时

- [ ] 复制 `src/hx-material.js`、`hx-interactions.js`、`hx-popup.js`、
      `hx-surfaces.js`、`hx-immersive.css`；
- [ ] 在 `<head>` 引入 CSS；
- [ ] 在 `<body>` 开头放 `.hx-filter-defs`（或让 JS 自动创建）；
- [ ] 按顺序引入四个 JS；
- [ ] 给至少一个按钮加 `hx-glass hx-light`；
- [ ] 确认 `HxMaterial.stats.hosts > 0`；
- [ ] 确认皮肤 `backdrop-filter` 包含 `url(...)`；
- [ ] 确认 CSP 允许 `img-src data:`。

**验收**：按钮出现折射；文字不模糊；控制台无 CSP/JS 错误。

**常见错误**：

- 把 `filter` 加在按钮或父容器；
- 皮肤被 `overflow:hidden` 裁掉；
- 背景纯黑，折射看不见（先换网格背景）。

---

## 阶段 2：布局与几何

- [ ] dock/nav 高度统一为 56px / 28px 圆角；
- [ ] 宽屏 dock 内边距 `0 14px 0 6px`；
- [ ] 封面 44/38px，按钮 38px，播放 40px；
- [ ] 搜索框 50px / 25px 圆角；
- [ ] 窄窗口两栏 44/56px；
- [ ] 合并单行 54/27px，球 54px；
- [ ] 详情 56px + 7 控制；
- [ ] 菜单 152/48/4/20；
- [ ] 模态 560/30/76vh；
- [ ] 抽屉 600/32 顶/66vh；
- [ ] 窗口 20px 圆角；
- [ ] 最大/全屏圆角 0。

**验收**：在 320/360/420/540/800/1200px 宽度下截图；无溢出、无错位、无
“窄窗口详情缩水”。

---

## 阶段 3：材质

- [ ] 每个宿主只有一张 skin；
- [ ] 宿主透明、relative、isolate；
- [ ] filter 按尺寸/圆角缓存；
- [ ] 轮廓法线正确（直边/四角/胶囊）；
- [ ] 肩部切向场存在；
- [ ] 环境边缘独立采样；
- [ ] `resultSigma` 消除球面层纹；
- [ ] popup 内部 tint；其他 profile 皮肤透色；
- [ ] 动态节点 `prepare`；
- [ ] resize 批处理（先读后写，4ms 预算）；
- [ ] 深度内部跳过不改变字节；
- [ ] 不支持 SVG filter 时有降级。

**验收**：

- 网格背景下折射方向正确；
- 球面无层纹；
- 胶囊上下沿轻微弯曲；
- 外缘有环境取色和透明内圈；
- 文字像素差 0；
- 缩放时不掉帧。

---

## 阶段 4：指针交互

- [ ] `.hx-light` 覆盖所有需要追光的按钮；
- [ ] 指针离开后 `--hx-mx/--hx-my` 清除；
- [ ] 窗口失焦/页面隐藏清除按压类；
- [ ] 按压只压 skin；
- [ ] 拖动不捕获 pointer，原生 slider/文本可用；
- [ ] 输入框/可编辑区域排除；
- [ ] 释放/取消回弹；
- [ ] 弹簧只在活动中跑 rAF；
- [ ] reduced motion 直接落位。

**验收**：

- 鼠标从任意方向离开，光斑回默认位置；
- 拖动时文字不动；
- 快速按下/移出/松开不残留 `.hx-pressed`；
- 任务管理器/Alt-Tab 后不残留形变。

---

## 阶段 5：菜单与弹窗

- [ ] 所有原生 `<select>` 替换为 `HxPopup.openMenu`；
- [ ] 菜单从触发器中心展开；
- [ ] 底部空间不足向上翻转；
- [ ] 左右不越界；
- [ ] 选中行系统蓝 + 蓝底，无勾选；
- [ ] 48px 行高，4px padding，20px 圆角，152px 最小宽；
- [ ] Esc/点击外部/滚动/失焦关闭；
- [ ] 选择项先关闭再 action；
- [ ] 方向键/Home/End/Enter/Space/Tab；
- [ ] 焦点归还触发器；
- [ ] 同时只有一个 popup；
- [ ] 740ms / 150ms 时序；
- [ ] 中途关闭不跳变；
- [ ] 菜单材质实时采样。

**验收**：用 `tools/smoke.cjs` 的菜单断言，或按 `popup-model.md` 的清单逐项
点击。

---

## 阶段 6：页面级编排

- [ ] 模态 520/220ms，焦点陷阱；
- [ ] 抽屉 540/240ms，贴底，抓取条；
- [ ] 搜索单节点形变，460ms；
- [ ] 详情 620ms 后显影；
- [ ] 详情退出 140ms 保持后淡出；
- [ ] dock/nav 460ms spring；
- [ ] 视图切换 token 防覆盖；
- [ ] Toast 220ms/2400ms；
- [ ] 所有计时器在切换时清理；
- [ ] Escape 层级正确；
- [ ] 从搜索进入详情，返回搜索。

**验收**：录屏逐帧看“先到位、后显影”；快速连点不闪烁；退出不跳变。

---

## 阶段 7：窗口

- [ ] `frame:false`、`transparent:true`、`backgroundColor:'#00000000'`；
- [ ] `show:false` + `ready-to-show`；
- [ ] 20px 圆角 + overflow hidden；
- [ ] 最大化保留任务栏；
- [ ] 全屏独立按钮；
- [ ] 最大化/全屏圆角 0；
- [ ] 标题栏 46×34，关闭 hover 红；
- [ ] 拖动区 28px，不挡控件；
- [ ] 启动画面圆角；
- [ ] 多显示器/DPI；
- [ ] 独立窗口（歌词/悬浮）状态清理。

**验收**：Win10/Win11、100/125/150/200%、多屏、最大/还原/全屏各截图。

---

## 阶段 8：性能

- [ ] 空闲 P95；
- [ ] 拖动 P95；
- [ ] 长菜单连续开合；
- [ ] 详情进入/退出；
- [ ] 搜索形变；
- [ ] 窗口 resize；
- [ ] 长任务 0；
- [ ] 文本像素差 < 1/255；
- [ ] GPU 内存不持续增长；
- [ ] 隐藏页面暂停动画。

**验收**：P95 < 33.5ms，max < 50ms，长任务 0；场景间冷却；真实 GPU。
