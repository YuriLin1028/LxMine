## Scope

This report validates the **generalized package and demo**, not the LxMine
production native-pixel approval. The 16-sample native EXQUISITE comparison,
negative control, system-menu comparison and packaged-app gate remain in the
LxMine `qa/material` pipeline, where they are bound to that app's source hashes.
The package's default optical values were extracted from those calibrated
captures; changing them requires a new native comparison, not just a demo rerun.

The smoke test is intentionally run on a software/headless Chromium fallback
with a 55 ms functional ceiling when Electron is unavailable; that is not a
release-grade performance result.
