# LxMine 重建

## 产品范围

以 LX Music 与 MineRadio 的功能并集为目标，重复入口和冲突行为由同一播放、队列、资料库与设置模型统一处理。此前 Folia 方案已停止，不再作为新桌面端的基座。

用户既有要求继续适用：支持自己添加 LX JS 音源、跨平台歌单导入、本地音乐、公开搜索、歌词、收藏、下载和音质选择；不强制平台账号，不沿用平台云同步；局域网双向发现，在接收方确认并持久化后覆盖设置、歌单与音源。

## 实现方向

- PC：保留 MineRadio 的视觉与桌面能力，接入 LX 源、资料库和局域网同步。
- 鸿蒙：原生 ArkUI 控件、华为沉浸光感、AVPlayer 与媒体会话；复用 MineRadio 视觉引擎。歌词与视觉覆盖整个播放页，避免固定矩形边界截断。
- 底部：单条紧凑播控胶囊，左侧导航圆形入口展开与收起；系统支持时接入握持感知。
- 多设备：手机和平板使用同一版本；折叠屏依据窗口空间、折叠状态和铰链区域布局，展开支持双栏，变化时保留当前播放、队列和滚动位置。
