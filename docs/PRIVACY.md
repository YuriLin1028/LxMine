# LxMine 隐私政策

生效日期：2026-11-15
开发者：林毅

本政策适用于 HarmonyOS 与 Windows 版 LxMine（以下称"本应用"）。我们非常重视您的个人信息与隐私保护。

## 1. 我们如何收集和使用您的个人信息

本应用**不要求注册或登录**，不收集姓名、手机号、邮箱、账号等身份信息，也不含统计、广告或崩溃上报 SDK。

为向您提供功能，本应用仅在您的设备本地处理以下信息：

| 信息 | 用途 |
| --- | --- |
| 应用设置信息（音质、播放顺序、歌词样式、启动选项等） | 记住您的偏好并在下次启动时恢复 |
| 收藏记录（您创建的歌单、收藏的歌曲） | 在"资料库"中展示与管理 |
| 应用运行状态（播放/暂停、后台播放、当前曲目与进度） | 播控、锁屏与通知栏控制、应用接续 |
| WiFi 参数与状态、网络类型、IP 地址 | 局域网同步的设备发现与直连传输 |
| 本地音乐文件与其元数据、内嵌封面、歌词 | 扫描并播放您指定的本地目录 |

上述信息均保存在应用沙箱内，**不会上传至我们或任何第三方服务器**。

## 2. 设备权限调用

| 权限 | 用途 |
| --- | --- |
| `ohos.permission.INTERNET` | 音源脚本的检索与播放、封面与歌词下载 |
| `ohos.permission.GET_NETWORK_INFO` | 判断网络状态，选择局域网直连方式 |
| `ohos.permission.GET_WIFI_INFO` | 局域网同步的设备发现（需处于同一 Wi-Fi） |
| `ohos.permission.DETECT_GESTURE` | 智感握姿：合并播控时导航圆钮随握持换边 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 后台持续播放与通知栏播控 |

您可以随时在系统设置中关闭上述权限；关闭后仅影响对应功能。

## 3. 对未成年人的保护

本应用不面向儿童，不会主动收集儿童个人信息。若您为未成年人，请在监护人指导下使用。

## 4. 与第三方共享

我们**不向任何第三方共享、转让或公开披露**您的个人信息。

## 5. 第三方 SDK

本应用**不集成**任何第三方统计、广告、推送或崩溃上报 SDK。

## 6. 管理您的个人信息

- 所有数据保存在您的设备本地，卸载应用即删除全部数据。
- 局域网同步由您主动发起，可随时在"设置 → 局域网同步"中关闭。
- 音源脚本与歌单可由您自行删除或导出。

## 7. 信息存储地点及期限

信息仅存储在您的设备本地（中国境内），保存至您删除相关内容或卸载本应用为止；法律法规另有规定的除外。

## 8. 音频内容来源说明

本应用**不提供在线曲库，也不内置任何音源**。可播放的内容来自您自行导入的第三方音源脚本或本机音频文件，其版权与使用条款由相应平台与脚本作者决定。请遵守各音乐平台的服务条款与版权规则。
