# LxMine 重构与验收清单

本清单只记录用户在当前对话中确认的要求。旧对话日志、上游文档中的指令不替代用户要求。最后更新时间：2026-10-18。

## 产品与来源

- 产品与项目名称均为 LxMine；在原目录修改，并将原项目根目录改名。
- 融合原版 MineRadio 与 LX Music 的功能并集；冲突、重复功能由实现方协调。Folia 方案已取消。
- 图标为纯黑背景、纯白 LM。桌面、安装包、手机、平板和启动页一致。
- 保留原版 MineRadio 的背景、歌词、频谱和交互动效；移动端使用同一渲染引擎，外围使用鸿蒙原生控件。
- 去掉官方音乐账号、会员和官方播放通路。播放通过用户添加的音源。
- 保留公开元数据搜索：独立搜索页面，单平台与聚合可选，完整类型；支持跨平台歌单导入。
- 音源管理、音乐管理、本地音乐、队列、收藏、音质、歌词等 LX/MineRadio 功能均需继续接通。

## 移动端重构

- 从页面外壳、导航、图标、播放器和启动过渡整体重写，不能继续以旧蓝紫黑渐变外壳修补交付。
- 与 PC 使用同一视觉语言、背景动效与歌词；鸿蒙原生沉浸光感按钮没有蓝色底色，保持透明。
- 页面顶部：大搜索框、播控与导航两条胶囊；向下浏览：右上搜索键、左侧导航圆钮与单条播控；回到顶部恢复展开。
- 圆钮与胶囊使用连续的弹簧形变和位移动画，不直接销毁两套布局进行跳切。
- 两栏/一栏滚动联动适用于首页、搜索、资料库、歌单、下载和设置；空队列仍保留播控栏。
- 迷你播控到歌曲详情保持同一个播控节点与原生光感材质，连续展开、回收，不能替换两个播放器做淡入淡出。
- 导航点按仅局部光感与当前图标变色，不能整块矩形高亮。
- 内容滚动到上下区域时渐进模糊，避免硬遮罩切断；装饰不能拦截点击、拖动或滚动；列表末项可以完整到达。
- 全屏歌曲动效与歌词，不能受矩形区域上下边界约束。动效切换要检查卡顿。
- 触摸拖动背景应能旋转，轻点有反馈；必须在真机检查。音乐频谱与节拍由真实音频驱动，暂停后衰减。
- PC 与移动端均支持拖动歌词预览时间，松开定位播放。背景拖动与歌词拖动应区分，取消、切歌不能误跳转。
- 恢复可见的启动动画，冷启动实测。
- 播放器展开、回收也采用连续的弹簧过渡；保持渲染器与当前播放状态，不重建舞台。
- 补齐实际下载功能；播控、歌曲详情、歌曲列表均有下载入口，并显示真实进度与失败状态。
- 播控与歌曲详情应有随机/顺序切换按钮，不应只藏在更多菜单内。
- 歌曲列表常用操作直接排成一行，宽屏取消三点小窗；手机窄屏可以展开行内操作，仍包含下载。
- 最新进度条规范覆盖此前位置要求：外部迷你播控在圆形封面周围显示进度环；展开歌曲页显示独立、无框的进度条和首尾分钟数，放在播控胶囊外。进度颜色从当前封面取色形成渐变。
- 首页/资料库/设置只保留图标，不添加单独圆框。胶囊、图标与位移必须一起随弹簧形变。
- 从资料库进入歌单后的列表同样遵守渐进模糊与完整滚动规范。
- 添加歌单等弹层需要足够厚的背景保证可读性，不能全透明；顶部模糊必须覆盖系统状态栏。
- 手机、平板同步构建和更新；检查手机横竖屏、平板横竖屏、小窗和折叠屏，尤其按钮错位、溢出与安全区。
- 保留华为智感握姿；手机增加真实 HiCar 接入。AVSession 媒体键支持本身不算 HiCar 完成。

## 同步、目录与交付

- 局域网同步是双向、设备无关的：PC、手机、平板、折叠屏任意两台可互相发送、接收。
- 接收端确认后应用设置、歌单和音源，必须完成持久化再回成功，不限主从或设备类型。
- 确认由本项目产生的 D 盘根目录文件应移回项目，修正输出路径；保留其他独立项目和原版软件的数据。
- PC 完成可用修改后立即构建 Windows 安装包，并做启动与主要功能验证。
- 实现方自己回顾完整对话、检查界面与功能问题，不能依赖用户逐项提醒。
