# PC 沉浸光感：真机标定与发布验收

此记录接续 `PC-MATERIAL-REVIEW-2026-10-18.md` 的问题复盘；旧文中的“当前实现”指修改前的版本。

## 本次实现

- `public/lxmine/material.js` 使用实时页面 backdrop、圆角轮廓法线和实测边缘位移衰减。移除了随机噪声折射与相互嵌套的模糊层。不是把手机截图铺在控件上。
- 依照手机像素校准折射方向、边缘混合、模糊、透色和高光；胶囊、圆按钮、菜单和弹层分别覆盖对应的原生材质等级。
- 表面形变与正文、命中区域分层。按压和拖动使用连续弹簧状态，释放、失焦和取消均有收尾路径；正文不会随皮肤缩放漂移。
- 修复 Escape 在队列弹层开启时直接关闭后方歌曲详情页的问题。

## 实测依据

手机 PLA-AL10，DPR 3.5，原生 `ImmersiveMaterial`，支持状态为 true，等级 `EXQUISITE=0`。四个场景、16 个样本，使用不同尺寸胶囊、圆按钮、圆角面板、THIN 菜单与 THICK 弹层；含网格和带文字背景。每组有材质开/关/再次开启截图与 UI 边界信息。

PC 与原生关闭材质的背景逐像素对齐；本次背景误差与原生重复拍摄误差均为 0。比较覆盖材质内部、折射带、中心、薄轮廓和外部阴影。关闭折射的负对照被门禁拒绝。

最终默认源码的结果：

- 16/16 样本通过；全内部平均绝对误差 1.27–7.48 / 255，折射带误差最高 11.02 / 255，外部阴影误差最高 1.67 / 255。
- 主体 SSIM 0.949–0.991。它不是“复刻完成百分比”。最外 1 CSS px 薄轮廓仍存在约 14–36 / 255 的平均差异，已单独报告，也纳入全内部误差门槛。
- 实际合成窗口、DPR 1、预热后的真实输入：拖动、播放页/弹层、窗口缩放三组 P95 均约 6.3ms；最大分别为 6.4、18.8、12.6ms；长任务均为 0。文字区域拖动像素差为 0。
- 缩放测试显式检查窗口可见、未最小化、后台节流关闭和文档可见；防止隐藏窗口降频污染帧时判断。

这些结果限定于本次设备、主题、场景与测试机器；没有宣称已还原华为闭源引擎或所有背景下逐个像素完全一致。
