# LxMine 版本说明

当前版本：**1.1.0**（2026-11-17）

版本号规则：`主版本.次版本.修订号`。功能与交互大改升主版本，新增能力升次版本，修复升修订号。
早期开发阶段所有构建都写作 `0.1.0`，从 1.0.0 起按实际变更递增。

后续版本的更新说明按 Windows 端、Android 端、HarmonyOS 端分别成节，共同改动在对应端的条目中分别说明。

---

## v1.1.0（2026-11-17）

### Windows 端

- 新增深色、浅色和跟随系统三种外观，采用深灰／浅灰页面背景，调整文字、图标、列表和控件的对比度。
- 播放页模糊封面随主题调整明暗，无封面时使用对应主题底色。
- 动效集中在播放页生效。原动效列表首项新增“关闭动效”，设置页和播放页均可切换，使用模糊封面和左对齐逐字歌词呈现播放页。
- 统一有动效与无动效时的歌词定位、逐字变色和滚动过渡，支持整屏歌词、上下渐隐、焦点行放大及周围歌词逐渐缩小，改善点击定位、焦点偏移、裁切和闪烁问题。
- 优化舞台预热、资源复用、前后台渲染和音频分析调度，减少打开播放页、切换动效时的重复加载及进度刷新引起的整页重建。
- 保留沉浸光感，控件按压适度放大。修复搜索球、首页胶囊、设置选择器和播放页操作球拖动时，玻璃层与图标、文字分离的问题，统一按压、拖动、松手和键盘反馈。
- 统一常驻底栏在播放页、其他页面及收起状态下的交互，修复部分场景消失、光感和按压反馈不同步的问题。
- 调整搜索结果的滚动区域与边缘过渡，修复列表上下内容被遮挡的问题。
- 新增 JS/TXT 音源批量导入，自动跳过重复脚本，单个文件失败后继续处理，汇总数量与失败原因，并保留当前启用音源。
- 扩展汽水音乐、酷狗音乐等平台的歌单分享链接识别，改进大歌单分页、完整性检查和导入错误处理。
- 增加歌曲封面及歌词补全与回退，改进切歌时的数据更新，处理旧歌曲信息覆盖新歌曲的问题。
- 改进下载保存到系统可访问位置的处理，下载完成后自动收纳进本地音乐。
- 修正局域网设备的平台名称，增加向 Android 容器发送同步的兼容处理，完善接收确认、拒绝、超时和重复请求处理。Windows 向卓易通内 Android 发送后的接收与拒绝已通过实机验证。

### Android 端

- 新增 Kotlin / Jetpack Compose 原生客户端，最低支持 Android 8.0，覆盖首页、歌单库、搜索、设置、播控和弹层，并与另外两端共享音源协议、歌单数据及舞台资源。
- Android 13 及以上提供液态玻璃、按压水球、折射和拖动交互。Android 12 及以下采用适配的普通点击反馈。
- 新增深色、浅色和跟随系统三种外观，采用深灰／浅灰背景，调整文字与控件对比度，核对并统一与 HarmonyOS 的设置及常用操作图标。
- 播放页模糊封面随主题调整明暗，无封面时使用对应主题底色。
- 动效集中在播放页生效。原动效列表首项新增“关闭动效”，设置页和播放页均可切换，关闭后使用模糊封面背景和左对齐逐字歌词。
- 统一有动效与无动效时的逐字变色、焦点定位和滚动过渡，支持整屏歌词、上下渐隐、焦点行放大及周围歌词逐渐缩小，改善歌词闪烁、硬裁切和点击定位跳变。
- 完善播放页手势，单指滚动和点击歌词定位，双指进出沉浸模式。启用动效时，歌词区域外支持单指旋转场景及触摸互动，并调整进出沉浸时的控制层过渡。
- 优化舞台预热、资源复用、前后台渲染和音频分析调度，减少重复加载、页面重建及页面外的持续渲染开销。
- 统一常驻底栏在播放页、其他页面及收起状态下的反馈，修复部分场景底栏消失和按压效果不同步的问题。
- 新增 JS/TXT 音源批量导入，自动跳过重复脚本，单个文件失败后继续处理，汇总数量与失败原因，并保留当前启用音源。
- 支持系统分享文本和应用深链导入，扩展汽水音乐、酷狗音乐等平台的歌单分享识别，改进大歌单分页、完整性检查及搜索结果追加与滚动。
- 增加歌曲封面及歌词补全与回退，改进切歌时的信息更新、系统下载目录及本地音乐收纳。
- 由原生媒体服务管理播放，接入通知栏和系统音频路由。
- 修正局域网设备的平台名称，增加卓易通等 Android 容器的同步接收兼容处理，用户确认后写入数据，并完善拒绝、超时及重复请求处理。

## v1.0.0 — 融合完成版（2026-11-14）

这是四平台融合、统一列表、歌单库重做与本地音乐接入后的第一个正式版本。手机、平板、车机共用
`cn.migu.music` 的 HiCar HAP；Windows 使用 `LxMine-1.0.0-Setup.exe`。

### 首页

- 首页从“四个平台各看各的”改为**四平台融合首页**：网易云、QQ 音乐、酷狗、酷我并发拉取后
  交错去重，榜单按“飙升 / 新歌 / 热歌 / 原创”等概念合并，封面保留单来源平台角标。
- 新增**每日三十首**：按日期种子从四平台新歌中确定性洗牌取 30 首，首张竖排卡片展示，点卡片
  进详情、点播放键直接开播。
- 新增**分类板块**：分类卡片进入对应平台的歌单列表；分类详情是临时视图，不写回首页。
- 顶部四大平台按钮改为**快捷胶囊**（新歌 / 歌单 / 排行榜 / 热门 / 分类）：沉浸材质、拖拽形变、
  激活白底、跟随滚动高亮、点击精准滚动到板块；窄窗自动只留图标。
- 首页排版对齐华为音乐：竖排长横幅、全屏出血横向卡片、无封面渐变+首字、平台角标内缩。
- 首页刷新与滚动性能：爬取结果延迟到停止滚动后应用，内容签名去重，禁止滚动中整页替换；
  播放进度按页面节流，避免每秒重建首页。

### 歌单库

- “资料库”更名为**歌单库**，主布局改为相册“时刻”式随机拼贴：卡片尺寸/比例随机，间距与
  窗口边距固定；首次随机后种子持久化，重启保持同一排列；右上角刷新按钮重新洗牌。
- 卡片封面统一回退到列表第一首歌曲封面；PC 端去掉重复的“我喜欢的”。
- 新增**本地音乐**卡片与页面：智能识别手机/电脑里的音频、导入系统音频文件、识别结果支持
  逐项勾选与全选；导入后读取时长、标题、歌手、专辑、内嵌封面，并解析 MP3/FLAC 内嵌歌词；
  应用内下载完成的歌曲自动登记进本地音乐。

### 歌曲列表与搜索

- 所有歌曲列表统一为标准 `song-row` / `SongRow` 和透明 `song-list`，去掉整块大圆角背景；
  首页新歌速递、板块详情、歌单详情、本地音乐、搜索结果不再各长一套。
- 每个歌曲列表头部统一提供 **播放全部** 与 **排列**：添加顺序、歌名首字母、歌手名、
  专辑名首字、手动排列。
- **手动排列改为拖动**：手机/平板长按歌曲拖动，PC 用鼠标拖动，落点即顺序，点“完成”应用；
  不再使用上下箭头。
- 每个列表右上角新增**搜索本列表**：只过滤当前列表的歌名/歌手/专辑，不触发公共搜索；
  本地音乐“智能识别”改用 sparkle 图标，与放大镜区分。
- “删除歌单”只在歌单库内可删除的歌单详情出现；我喜欢的、最近播放、本地音乐、搜索页、
  首页板块不出现删除入口。
- PC 搜索歌曲列表与其他列表同构；行操作按窗口宽度切换：宽窗直接显示下载/爱心/加号，
  窄窗收为下载+展开；详情页返回按钮与标题同一水平线。

### 视觉、材质与多端一致

- 二级及以下页面统一 `PageHeader`：38vp 材质球、20vp 图标、28vp 标题，视觉顶边
  `statusInset + 6vp`；返回键恢复旧版“小于号”描边观感。
- 歌单库一级页操作球统一 38vp；材质保留 `systemMaterial` 沉浸光感与拖拽形变，
  不再用组件级 blur 替代。
- 播放页顶排、首页胶囊、快捷播控的材质上伸补偿、图标随球形变、投播覆盖层命中穿透全部统一。
- 手机竖屏为主，播放详情可横屏沉浸；横屏两指上滑显示/下滑隐藏控制层。
- PC 与移动端同步：顶栏、列表、歌单库拼贴、行内操作、本地音乐、搜索/排序、浮层交互。
- 修复全屏浮层 `HitTestMode.Block` 连子节点一起阻断导致“窗口可见但按钮/拖动全无响应”的问题；
  智能识别全选窗口与手动排列窗口均已修复。
- 修复系统菜单关闭动画未结束时打开全屏浮层被遮罩挡住触摸的问题。

### 交付物

- Windows：`LxMine-1.0.0-Setup.exe`
- HarmonyOS：`LxMine-1.0.0-HiCar-20261114.hap`（`cn.migu.music`，手机/平板/车机共用）

## v0.1.0 — 四平台首页开发版（2026-10-17 ~ 2026-10-19）

这是 LxMine 重建后的早期可用版本。首页仍是**四大平台入口**，每个平台各自一套内容；后续的
融合首页、歌单库拼贴、本地音乐和统一列表工具都还不存在。

### 主要能力

- **四平台首页**：网易云、QQ 音乐、酷狗、酷我四个入口，切换平台查看各自的推荐/新歌/榜单。
- **四平台搜索**：LX 音源搜索支持 kw / kg / wy / tx 四路来源与平台切换，搜索结果带专辑封面、
  分页加载；自定义音源脚本可导入、启停、切换。
- **播放与歌词**：播放详情、动态歌词、播放队列、播放顺序；PC 独立桌面歌词窗口，
  Harmony 原生启动动画与后台播放。
- **歌单与设置**：本地歌单、最近播放、我喜欢的、音源管理、音质/播放顺序等设置。
- **多端基础能力**：鸿蒙手机/平板真机安装；PC 无边框窗口、托盘/自启；同一 Wi-Fi 下
  手机与 PC 双向发现并同步歌单、音源和设置。
- **PC 视觉基座**：MineRadio 沉浸材质、指针追光、原生菜单、播放详情与底部播控栏的初版校准。

### 当时的已知限制

- 四个平台内容彼此独立，首页、榜单、歌曲列表的排版和交互不统一。
- 没有融合首页、每日三十首、分类板块、歌单库拼贴。
- 没有本地音乐导入/识别，也没有“播放全部 + 排列 + 列表内搜索”的统一列表工具。
- 手机、平板、PC 的顶栏、列表行、弹层和材质细节存在差异。
- 版本号固定为 0.1.0，构建产物靠日期/后缀区分。

## 从 0.1.0 到 1.0.0 的变化概览

| 维度 | v0.1.0 | v1.0.0 |
|---|---|---|
| 首页 | 四大平台各自入口 | 四平台融合 + 每日三十首 + 分类 + 快捷胶囊 |
| 榜单 | 按平台分开 | 同概念跨平台合并，内部歌曲保留来源角标 |
| 歌单库 | 普通资料库列表 | 时刻相册式随机拼贴，种子持久化 + 刷新 |
| 歌曲列表 | 各页样式不一 | 统一 SongRow / 透明 song-list |
| 列表工具 | 基本没有 | 播放全部 + 五种排序 + 拖动手动排列 + 列表内搜索 |
| 本地音乐 | 无 | 识别/导入/全选/元数据/封面/歌词/下载自动收纳 |
| 视觉 | 各端各自实现 | 统一顶栏、38vp 材质球、材质与形变规范 |
| PC 对齐 | 部分页面 | 搜索/列表/详情/歌单库/本地音乐与移动端同构 |
| 版本管理 | 固定 0.1.0 | 1.0.0 起按语义化版本递增 |
