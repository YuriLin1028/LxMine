## 2. 应用介绍（≤8000 字符）

```text
LxMine 是一款面向 HarmonyOS 的本地优先音乐播放器，界面与桌面版同源，覆盖首页、歌单库、
统一歌曲列表、搜索、本地音乐与沉浸式播放详情。

主要功能：
· 融合首页：每日三十首、跨平台榜单合并、分类板块，一屏看到各来源的新歌与歌单。

· 播放详情：沉浸视觉与逐行歌词，支持翻译、罗马音与时间偏移。
· 局域网同步：手机、平板与电脑之间双向同步歌单、音源与设置。
· 应用接续与后台播放，锁屏与通知栏均可控制。

说明：
· 应用不提供在线曲库，也不内置任何音源；可播放的内容来自用户自行导入的第三方音源
  脚本或本机音频文件。
· 无账号体系，不需要登录；歌单与设置均保存在本机。
· 开源项目（GPL-3.0），源码与第三方声明见项目主页。
```

## 4. 权限用途说明

| 权限 | 用途 | 用户拒绝后 |
| --- | --- | --- |
| `ohos.permission.INTERNET` | 音源脚本检索与播放、封面与歌词下载 | 仅能播放本地音乐 |
| `ohos.permission.GET_NETWORK_INFO` | 判断网络状态，选择局域网直连地址 | 同步可能失败 |
| `ohos.permission.GET_WIFI_INFO` | 局域网同步的设备发现（需同一 Wi-Fi） | 无法发现附近设备 |
| `ohos.permission.DETECT_GESTURE` | 智感握姿：合并播控时导航圆钮随握持换边 | 圆钮不随握持换边 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 后台持续播放与通知栏播控 | 切到后台即停止播放 |

Store 包已移除 `ACCESS_CAR_DISTRIBUTED_ENGINE`（构建脚本自动处理），审核时不应看到车机权限。
